# القرار محسوم: A + F3 Almarai

اعتمد المالك تخطيطA وخط**F3 Almarai** بعد المقارنة. الجسم400، والتأكيد700 حيث استخدمته المعاينة؛ لا وزن700 لجميع النصوص. العربيةRTL والإنجليزيةLTR والأرديةRTL، كلهاAlmarai معPlex للحروف غير المدعومة فقط.

النطاق الحالي دمج الخط في تجربة تفاصيل المعدة الحقيقية. لا إعادة مقارنة أو طلب اختيارF1/F2/F3. الأصول والمقارنة التاريخية محفوظة، وNoto ليس خيارًا معتمدًا للشاشة المرحّلة.
