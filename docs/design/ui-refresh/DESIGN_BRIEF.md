# ثلاثة اتجاهات لواجهة إدارة المعدات

شريحة مقارنة قابلة للتشغيل، لا ترحيل للتطبيق الإنتاجي. المالك يستطيع العمل وحده، والمعدة محور العمل. العربية أولًا مع الإنجليزية والأردية. نفس البيانات والأفعال في A/B/C.

## المصدر والحدود
المصدر `8aae24f`؛ إصلاح تسلسل تواريخ المستندات واختباره مدمجان. تفحّصنا الرئيسية والمعدة والمصروف والتفاصيل المالية ومنزل السائق في المصدر، وصورة M7 المرجعية. لا خدمات محلية على 8080/8081 وقت الفحص؛ لم نلتقط baseline مسجّل الدخول ولم نحاول OTP. الصورة القديمة مرجع هيكلي فقط؛ نسب النمو/المخططات/حالات التشغيل فيها ليست متطلبات.

ملاحظات baseline: الرئيسية تستخدم بطاقات بعرض ثابت 245، والتفاصيل توزّع الإجراءات والسياق بين قوائم طويلة، ونموذج المصروف يضع خيارات الحالة والسياق في تسلسل طويل. نجرب ترتيب الأولويات، عرضًا تكيفيًا، وخطوطًا مقروءة دون تعديل العقود.

## ثوابت المقارنة
- الرئيسية: انتباه أولًا، مصروفات وإيرادات **مسجلة** في أكتوبر 2026 بحسب تاريخ العملية، ثم السجلات والمعدة. لا صافي ربح أو رصيد بنك أو نسب نمو.
- المعدة: اسم وموديل ومرجع؛ المصروف/الإيراد في المقدمة، المستندات والبلاغات والصيانة، ثم ارتباطات اختيارية.
- المصروف: اختيار المعدة مسبقًا، دفع كامل ظاهر افتراضيًا، جزئي/غير مدفوع مع متطلبات الطرف، تاريخ دفع منفصل، مشترك/عام ومشروع اختياري.
- المرفق يأتي بعد الحفظ الحقيقي في التطبيق الحالي. المعرض يجرّب عرضه وفشله وإعادته محليًا فقط، و«اختبار النموذج» يصرّح بعدم حفظ أي سجل.
- القيم الدقيقة والتواريخ من أدوات العرض الحالية؛ لا API أو جلسة أو قاعدة بيانات أو صلاحيات أو migrations معدّلة. مثال الإجمالي/الدفعات/المسترد/الصافي/المتبقي = 1000/600/200/400/600 عبر عمر السجل.
- غياب الإذن وفشل التحميل لا يعرضان صفرًا. أسماء المعدة العربية بيانات مستخدم ثابتة لا تترجم عند اختيار الإنجليزية.

نستخدم مهارة `ux-writing-arabic` للنسخ المختصر والواضح؛ الترجمة الأردية تجريبية وتحتاج مراجعة لغوية بشرية لاحقًا.
