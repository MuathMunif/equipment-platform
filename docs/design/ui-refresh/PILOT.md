الصور كلها ملتقطة من **التطبيق العادي `lib/main.dart`** على8081، بعد الدخول الطبيعي برقم التطوير الاصطناعي0500000802 ورمز التطوير المعلن. ليست fixtures المعرض. أُعدت عبر API العادي معدتان اصطناعيتان فقط في مساحة مالك الاختبار الموجودة: EQ-000037 بها مصروف1850 وإيراد4500 مسدد جزئيًا ومستند تأمين وبلاغ وصيانة؛ EQ-000038 فارغة. البيانات محفوظة في PostgreSQL التطوير، ولا تتضمن عملاء حقيقيين أو مفاتيح إنتاج. لم يُحفظ token في ملفات الدليل.

حُفظت لقطتا قبل الترحيل من البناء الإنتاجي السابق قبل استبدال الخادم المحلي بالبناء الجديد. الصور بعد الترحيل: ar390/ar1440، en390، ur390، فراغ ar1440/ur390، سجل المال والارتباطات على الجوال، وiOS عربي (10 صور مع لقطتي قبل). انظر [SCREENSHOTS.md](SCREENSHOTS.md). اللقطات الإنجليزية/الأردية العلوية سبقت تعديل لون زر البحث الموجود أسفل الجزء الظاهر؛ تخطيطها ومحتواها لم يتغيرا. لقطات العربية وiOS وبناء التسليم تتضمن إصلاح التباين.

على الويب تحقق الدخول وقائمة المعدات وصفحة المعدة ثم نموذج المصروف الصحيح والعودة دون حفظ إضافي. فتح صف الإيراد في السجل أعاد تفاصيل الأصل نفسه: إجمالي4500، مستلم3000، متبقٍ1500. فُتحت الارتباطات الاختيارية والسجل أسفل الجوال وصُوّرا. تبديل اللغة عبر إعداد الحساب، وأعيدت العربية. على iOS تحقق الدخول → المعدات → تفاصيل المعدة → إضافة مصروف والعودة → المستندات ذات تاريخ15 أكتوبر2026. هذه عينة smoke متصلة، لا حملة قبول native كاملة.

Docker كان معلقًا حتى لأوامر القراءة. بعد موافقة المالك الصريحة على إعادة تشغيله (لتأثيره المحتمل في مشاريع أخرى)، فشل restart العادي بانتهاء المهلة؛ نجح `docker desktop stop --force --timeout 30` ثم `docker desktop start --timeout 60`. لم تُحذف volumes.
