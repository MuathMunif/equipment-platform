## التغيير المنفذ

تحية متواضعة واسم المساحة في شريط الرئيسية، مع الإعدادات وتبديل المساحة والإشعارات واللغة والتحذير التطويري. أزيل العنوان التمهيدي المكرر. لم تتغير الرئيسية المبسطة للسائق.

الملخص المالي قصير، والتحكم بالشهر ضمن رأسه. الانتباه المؤكد فارغًا لا يرسم بطاقة؛ الإخفاق يظهر إعادة محاولة. عند وجوده تظهر أول3 بنود بترتيبAPI وروابطها، ومجموعة المراجعة تستخدم pendingCount الفعلي. استكمال البيانات صف مستقل عند وجوده فقط؛ لا يضاعف عدد التنبيهات.

بطاقة عمليات واحدة بصفوف ذات نوع ومبلغ وتاريخ ورابط الأصل. قسم «معداتي» يعرض أول3 من البيانات المتاحة بأيقونة محايدة ومرجع داخلي، مع عرض الكل وإضافة معدة للمصرح له. البحث بقي كاملًا في صفحة المعدات والتبويب، والمالك الجديد يرى إضافة أول معدة فورًا. على سطح المكتب العمليات والمعدات في عمودين.
